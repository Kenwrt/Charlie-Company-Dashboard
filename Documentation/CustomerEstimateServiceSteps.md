# Required customer estimate content

Saved from the owner's instructions on October 2, 2026 for future implementation of the final customer estimate. Every estimate created must contain the service steps, final walkthrough statement, payment schedule, and monthly payment invitation below. This is the retained content requirement; storing this document does not implement automatic inclusion in generated estimates.

## 1. Demo & Removal

- Remove all existing deck surface boards on both levels.
- Remove all existing guardrails/handrails on upper deck, lower landings, and both stair runs.
- Remove all existing stair stringers and treads down to primary framing/footings.
- Detach and dispose of all removed fasteners, hardware, and debris.
- Haul away and legally dispose of debris; leave work areas broom-clean daily.

## 2. Framing – Inspect & Selective Repair

- Inspect all existing beams, posts, ledger, and joists for rot, excessive checking, and deflection.
- Retain approximately **70% of existing joists and framing** that are structurally sound and code-compliant.
- Replace or sister any damaged/undersized joists and rim sections that do not meet span or load requirements.
- Install additional blocking and bracing at:
  - Deck board butt joints and picture-frame edges.
  - All new rail post locations.
  - Stair stringer connections at top and bottom.

## 3. New Stair Stringers & Treads

- Layout and cut new stair stringers for both stair runs to meet current code for rise/run and uniformity.
- Install new pressure-treated stringers with appropriate hardware to existing framing and landings.
- Install new treads (wood or composite per selection) with approved fasteners; maintain consistent nosing and overhang.

## 4. New Decking – Upper Deck, Platforms, and Stairs

- Supply and install new decking boards on:
  - Main upper deck.
  - Intermediate and bottom platforms.
  - Stair treads (if using same decking material).
- Install boards with manufacturer-approved fastener system (hidden fasteners/face screws with plugs as specified).
- Maintain proper gapping and overhangs, and neatly cut around posts and obstructions.
- Install picture-frame border detail where specified, with necessary blocking.

## 5. New Rail System – All Levels & Stairs

- Remove old rail layout and install new rail system on:
  - Main upper deck perimeter.
  - Intermediate platform.
  - Bottom platform edges where required by code.
  - Both stair runs.
- Install new structural rail posts (wood or steel per design) tied into framing with blocking and structural hardware.
- Build horizontal rail style (to match reference photos) or chosen system, maintaining code-compliant height and maximum opening between horizontals.
- Install continuous handrail on stairs if required by local code.

## 6. Hardware, Flashing & Detailing

- Replace corroded or non-compliant hardware with new code-approved fasteners, hangers, and connectors.
- Confirm ledger flashing is present and intact; repair or replace flashing as needed.
- Apply protective coating (joist tape/joist paint if selected) on exposed framing tops before decking installation.

## 7. Cleanup & Final Walkthrough

- Final cleanup of deck, stairs, and yard area; remove all construction debris and packaging.
- Sweep/blow off all walking surfaces.
- Conduct walkthrough with owner/rep to verify rail layout, stair comfort, and deck finish; address punch-list items.

## Final Walkthrough

We complete a final walk-through (or photo report) to ensure quality. Any touch-ups are handled before we close the project.
